# About Traccar

Traccar is a modern GPS tracking platform that can track GPS devices enables real-time. A GPS device can be associated with a vehicle, asset, person etc.

![Traccar Screenshot](./traccar-home-page.webp)

## Traccar Features

### 1. Server Agnostic
- Traccar offers exceptional performance and stability across all platforms, including Windows and Linux.  
- It can be hosted on-premise or in the cloud, with professional hosting and support options available.

### 2. 2000+ Devices Supported
- Traccar supports **1500+** GPS tracking devices and **250+** communication protocols.  
- From affordable generic models to premium brands, it gives you the freedom to choose any compatible GPS tracker.

### 3. Modern UI
- The platform features a modern, user-friendly web interface optimized for both desktop and mobile.  
- Native Android and iOS apps are available, and mobile devices can also function as GPS trackers using Traccar’s companion apps.

### 4. Live Tracking
- Traccar provides real-time location updates with zero delay.  
- It supports multiple map views, including road and satellite imagery, and can process extensive sensor data from GPS units efficiently.

### 5. Alerts
- Receive instant notifications via push, email, and other channels.  
- Traccar alerts you to events such as harsh driving, fuel drops, maintenance schedules, and geofence breaches.

### 6. Reports
- Access detailed reports including trip history, charts, and summaries directly from the web or mobile app.  
- Reports can be exported to Excel, and location history can be visualized on maps for deeper insights.
